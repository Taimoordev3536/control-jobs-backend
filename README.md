# NECTAR x DTL Loyalty Program Backend

This is the Nest.js backend for the NECTAR x DTL Loyalty Program, handling authentication, receipt uploads, points, and rewards.

## Installation

1. Install dependencies:
   ```sh
   npm install
   ```

2. Set up PostgreSQL and update `.env` file.

3. Run the project:
   ```sh
   npm run start:dev
   ```
